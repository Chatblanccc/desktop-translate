# Phase6 前端视觉重构产品规范

## 目标

在不新增业务功能、不改变翻译与隐私逻辑的前提下，统一桌面翻译的设置窗口、结果卡片、悬浮球和托盘文案，使产品呈现现代、克制、可信的 Windows 桌面工具体验。

## 选定方向

- 视觉基准：[`references/selected-direction-1.png`](references/selected-direction-1.png)
- 关键词：清晰、轻量、可信、本地优先、Windows 原生感
- 主色：稳定蓝色品牌色；状态色只表达成功、警告、故障和危险
- 层级：侧边导航 + 单一滚动内容区；优先使用留白和分隔线，减少嵌套卡片与阴影
- 组件：统一按钮、切换开关、单选项、表单、状态提示和危险操作

## 信息架构

1. 常规与外观：悬浮球、吸附、位置、主题。
2. 划词取词：启用状态、本地 OCR 使用方式、监听状态。
3. 在线翻译：开关、语言、凭据、授权与服务条款。
4. 隐私与关于：本地数据清理、原生服务状态、应用版本。

四个导航入口分别打开独立设置视图；右侧内容区独立滚动，保留原有控件语义和业务流程。

## 设计系统

- 字体：Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI。
- 圆角：6px 控件、9px 导航与徽标、12px 容器、999px 胶囊状态。
- 间距：以 4px 为基础节奏，主要内容间距使用 8/12/18/24/42px。
- 动效：140ms 状态过渡；尊重 `prefers-reduced-motion`。
- 可访问性：键盘焦点可见、禁用态明确、状态使用 `aria-live`、危险清理确认自动聚焦。
- 图标：使用 Fluent UI React Icons；品牌图标复用现有 `translate-mark.svg`。

## 行为约束

- 不新增网络请求，不改变在线翻译默认关闭策略。
- Provider 凭据仍只由 Electron Main 解密和使用；界面仅明文回显 APP ID，密钥输入值保持为空并使用固定掩码表示已保存状态。
- 设置快照加载失败时禁用可变更控件，避免用户误操作默认占位状态。
- 结果卡片继续保持固定窗口、非任务栏和本地原文回退行为。
- 悬浮球尺寸和拖动/吸附机制不变。

## 验收标准

- 设置窗口默认定位到“划词取词”，视觉结构与选定方案一致。
- 四个导航入口均可聚焦、点击并定位到对应区域。
- 浅色、深色、系统主题均具备足够文字与状态对比度。
- 结果卡片、悬浮球和托盘不再展示内部 Phase 标签。
- 单元测试、类型检查、构建与现有端到端流程通过。
- 真实应用截图与参考图完成并排设计 QA，根目录 `design-qa.md` 的最终结果为 `passed`。
